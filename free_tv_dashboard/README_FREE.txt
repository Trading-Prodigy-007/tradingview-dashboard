FREE HOSTING VERSION — GitHub Pages

Daily workflow after one-time setup:
1) Put the 5 TradingView CSVs + 2 screenshots into the Incoming folder.
2) Leave start_watcher.bat running (or add it to Windows Startup later).
3) It processes the files, updates the static website, archives the 7 inputs, and pushes the new site to GitHub Pages.

Yellow rule: Revenue growth %, Quarterly YoY > Revenue growth %, TTM YoY.
Relative Volume EP is shown unchanged.
Latest screener tables overwrite prior screener tables.
Chart screenshots accumulate by date.

Requirements already compatible with the user's current setup:
- Python
- pandas
- Pillow
- Git for Windows (for automatic free publishing)

The repo/site can be public on GitHub Pages. Anyone with the URL can view it.
